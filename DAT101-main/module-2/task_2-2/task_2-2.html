1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Du burde bruke const hvis verdien ikke skal endre seg og bytte til let når du vet at verdien må endres senere i koden. Du burde bruke variabler hvis du vil lagre informasjon du har bruk for senere. Ikke alle kan være constant fordi noen verdier kan endres av ulike grunner.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Paranteser tvinger datamaskinen til å regne det som er inni parantesen først. Dette lar deg bestemme hvilken rekkefølge du vil at noe skal utregnes.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. Vi kan forhindre desimaler ved å bruke .toFixed(0) etter svaret som har desimaler.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. De kan bli like hvis man bruker .toFixed(1) etter svaret til tallet med flest desimaler. Slik kan den bli rundet opp til 12.2.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators returnerer en bolsk verdi og vi kan sjekke at de er falsk eller sann ved å bruke en if statement.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() fungerer slik at den gir ett tilfeldig tall. Den kan bli brukt for spillprogrammering f.eks for å se om en fiende klarer en "deception check" ved å treffe over ett spesifikt tall for å kunne lykkes.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus er en måte å regne resten av en divisjon. Den kan bli brukt hvis du vil finne det som blir til overs etter en deling.
